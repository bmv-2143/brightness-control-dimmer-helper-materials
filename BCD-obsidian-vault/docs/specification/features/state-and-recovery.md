[Глоссарий: термины и обозначения](../glossary.md). Местные пояснения сохраняют тот же смысл.

CAP-004. Точный reboot-контракт PENDING_USER Q-001 исключён из правил ниже. Согласованы выбор политики с Auto default и опциональный возврат overlay с выключенным default в «Последнем режиме BCD»; 2026-10-06 подтверждён третий режим «Заданная яркость». Время/recovery и остальные параметры ещё согласуются в [подготовке](../../workflows/full-rewrite-preparation.md). Нет обещания перезапуска после force-stop/system stop/crash.

Deadline относится к текущей загрузке; хранение/поведение через reboot не выбрано. После перезапуска процесса с просроченным deadline не начинать новый полный срок. Таймер не требует новых exact-alarm grants и debug ускорения. Предлагаемые тесты должны отдельно проверить virtual time логику и реальную доставку/ограничения ОС.
