Сохраняются gaps из discovery-coverage: применение системных настроек на OEM-устройствах, overlay и касания, фоновые ограничения API 26–37, распознавание foreground-приложения, покупка/реклама, восстановление после прекращения процесса. Никакие изменения в Android-проекты и существующие заметки Obsidian не внесены. Будущие исполняемые тесты, acceptance driver (посредник тестовых действий) и реализация приложения вне этой задачи.
