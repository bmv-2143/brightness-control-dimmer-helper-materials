# Сохранённая установка Git Overview Stripes

В `installed/` сохранены `main.js`, `manifest.json`, `styles.css` и исходный
`README.md` из существующей установки версии 1.0.1. Это копия установленных
файлов, а не проект сборки исходного плагина. Файлы скопированы без изменений.

В `releases/` сохранены существовавшие ZIP-архивы версий 1.0.0 и 1.0.1.
`SHA256SUMS.txt` содержит SHA256 исходных байтов всех сохранённых файлов;
контрольные суммы фиксируют локальную копию, а не подтверждают её происхождение
от внешнего издателя. Для `installed/` нормализация переводов строк отключена
через `.gitattributes`, чтобы при восстановлении сохранить исходные байты.

## Восстановление

1. Закрыть Obsidian.
2. Создать `BCD-obsidian-vault/.obsidian/plugins/git-overview-stripes/`.
3. Скопировать туда `main.js`, `manifest.json` и `styles.css` из `installed/`.
   При необходимости скопировать также `README.md`.
4. Открыть хранилище и включить Git Overview Stripes в Community plugins.
5. Проверить отображение изменений в заметке, находящейся под Git.

Рабочая установка в `.obsidian/plugins/` игнорируется. При обновлении плагина
обновлять сохранённую копию отдельным осмысленным коммитом и пересчитывать
контрольные суммы. Не изменять сохранённую копию автоматически при запуске Obsidian.

Описание самого плагина и его настроек находится в `installed/README.md`.
